# SkillBridge

Explainable Internship Matching and Skill-Gap Analysis Platform.

## Description

SkillBridge connects students with suitable internship opportunities
using skill compatibility, academic eligibility, preferences and
semantic similarity.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- Python FastAPI
- PostgreSQL
- pgvector
- Sentence Transformers
